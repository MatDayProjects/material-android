- [`0be4ae5`](https://github.com/MatDayProjects/material-android/commit/0be4ae533d1cd7a9b02985c53b5556a55029ef3b) replaces broad QEMU data-tree pruning with a manifest-owned seven-file allowlist for OpenVM's supported headless `q35`/`virt` command paths. Run 31298940769 proved that removing documentation, keymaps, and man pages was still too generous; collection now rejects missing or symlinked data and the workflows compare the emitted list with `qemu-build.json`. / 將粗略剔 QEMU data tree 改成由 manifest 管住七件檔案嘅 allowlist，專畀 OpenVM 支援嘅 headless `q35`/`virt` command paths。Run 31298940769 證明剔走 documentation、keymaps 同 man pages 都仲太闊；而家缺件或者 symlink data 會即刻拒絕，workflow 仲會對返 `qemu-build.json`。
- [`be4edd3`](https://github.com/MatDayProjects/material-android/commit/be4edd346d66ad1e592ac51719a525d61f7f41aa) keeps only runtime QEMU data under the 64 MiB packaging cap, records the filtered byte count and excluded documentation-only trees, and makes native workflows validate that evidence before packaging. The full `share/qemu` tree was carrying a small library's worth of bedtime reading. / 將 runtime QEMU data 收喺 64 MiB packaging cap 之下，記低 filtered byte count 同排除咗嘅 documentation-only trees，native workflows package 前亦會驗證呢啲 evidence。之前成個 `share/qemu` 好似帶住一間細型圖書館嘅睡前讀物。
- [`68da202`](https://github.com/MatDayProjects/material-android/commit/68da2024fd0f8604ba213ba78e7bccd76e1e443e) allows the collector to resolve Android's public `libOpenSLES.so` linker-namespace dependency without copying it from Termux; the installed API 37 emulator confirms the platform library exists. Every other missing runtime dependency remains a hard failure. / 俾 collector 認到 Android 公開嘅 `libOpenSLES.so` linker-namespace dependency，唔使由 Termux 搬埋一份入嚟；已裝 API 37 emulator 證實平台真係有呢個 library。其他缺失 dependency 繼續一律硬拒絕。
- [`d4603a9`](https://github.com/MatDayProjects/material-android/commit/d4603a9e14ca766141d826a41b7fe60879051282) creates the validated runtime output parent before collection, while keeping the collector's refusal to replace an existing output leaf. The package build had finished; the missing parent was the only thing still waiting outside the door. / 建立驗證過嘅 runtime output parent，但保留 collector 拒絕覆蓋現有 output leaf 嘅規矩；package build 明明已經完成，得返個未出世嘅 parent 喺門口等緊。

The hosted native build and Android guest boot remain unverified. / 用鎖定版本嘅開源 QEMU 配方砌好兩個 host ABI、包入 nativeLibraryDir，再用 emulator 睇實 production controller；hosted native build 同 Android guest boot 仲未驗證。

## 0.1.0 · 2026-08-08

- Created the OpenVM Android project from an empty repository.
- Added local VM profile management, image URI import, JSON import/export, and local history.
- Added backend readiness reporting for AVF and QEMU boundaries.
- Added settings for language mode, funny levels, emoji decoration, display name, and theme.
- Added a bounded regex builder and keyboard command palette.
- Added unit/instrumentation test scaffolding and a GitHub Actions signing workflow.
